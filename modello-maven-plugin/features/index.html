Modello Features Demo

Displays results from some key generators on features.mdo that is intended as a testbed for Modello features:

  • xdoc,
  • xsd,
  • Java code generators (Java model + readers/writers) results are visible in JavaDocs and Source Xref.

Modello executions are configured in pom.xml:

<executions>
  <execution>
    <id>standard</id>
    <goals>
      <goal>java</goal>
      <goal>xpp3-reader</goal>
      <goal>xpp3-writer</goal>
      <goal>dom4j-reader</goal>
      <goal>dom4j-writer</goal>
      <goal>jdom-writer</goal>
      <goal>stax-reader</goal>
      <goal>stax-writer</goal>
    </goals>
  </execution>
  <execution>
    <id>site-xsd</id>
    <phase>pre-site</phase>
    <goals>
      <goal>xsd</goal>
    </goals>
    <configuration>
      <outputDirectory>target/generated-site/resources/xsd</outputDirectory>
    </configuration>
  </execution>
  <execution>
    <id>site-doc</id>
    <phase>pre-site</phase>
    <goals>
      <goal>xdoc</goal>
    </goals>
  </execution>
</executions>
